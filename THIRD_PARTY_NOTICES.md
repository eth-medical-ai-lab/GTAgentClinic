## Libraries

Installed from npm by `npm ci`; none are copied into this repository. The neural-voice libraries (kokoro-js, transformers.js, ONNX Runtime, phonemizer, sharp) are optional: only `npm run voices:install` installs them, into `voices/node_modules`. The browser demo includes the licences for its bundled libraries in `dist/demo/dependency-licenses.txt`.
